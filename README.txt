PROJECT TITLE  : Agriculture Crop Price Information System
                 with AI-based Price Prediction
TECHNOLOGY     : Python Flask + SQLite + HTML/CSS/JS
DATABASE       : SQLite (No installation needed!)
PROJECT TYPE   : Web Application (Full Stack)
LEVEL          : MCA Final Year Main Project

────────────────────────────────────────────────────────────
 INSTALLATION – ONLY 2 STEPS!
────────────────────────────────────────────────────────────

STEP 1 – Install Flask
───────────────────────
  pip install flask

STEP 2 – Run the Application
──────────────────────────────
  python app.py

STEP 3 – Open in Browser
──────────────────────────
  http://localhost:5000

  That's it! Database is created automatically on first run.
